# Arsip contoh — BUKAN template kerja

Folder ini menyimpan salinan utuh produksi contoh **karhutla, Oktober 2026**,
yang dulu menjadi isi `template/`:

- `animatic-karhutla-2026-10.html` — adegan karhutla (ASAP, KARHUTLA,
  Data Kemenkes, PM2.5).
- `words-karhutla.js` — timestamp kata karhutla (122 kata, sampai 53,916 detik).
- `naskah-karhutla.txt` — naskah karhutla.

**JANGAN pakai file-file ini sebagai dasar video baru.** File-file ini hanya
arsip referensi: contoh bagaimana satu produksi jadi (adegan, timing kata,
transisi) terlihat saat sudah diisi topik nyata.

Template kerja yang benar ada satu tingkat di atas folder ini:
`template/animatic.html`, `template/words.js`, dan
`template/naskah-contoh.txt` — semuanya sudah dibersihkan jadi placeholder
generik. Setiap produksi baru WAJIB mengganti seluruh teks adegan, CAPW,
dan `words.js` dengan isi topiknya sendiri.

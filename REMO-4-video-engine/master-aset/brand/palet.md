# Brand — Palet

## Palet utama: laut dalam (remo-3 v1, v3, v4)

Diambil dari `:root` di `animatic.html` v3 (file template gabungan).
Ini palet default untuk topik laut/lingkungan. Topik lain WAJIB punya
palet sendiri (lihat contoh art direction di `visual/`), tapi struktur
variabelnya sama: gelap → dominan → aksen → teks terang.

## Palet gaya flat Hari (tes bernafas-air)

- Latar beige: **#F0E7D8** (diukur dari piksel gambar contoh di
  `visual/contoh-gaya-flat/` — bukan nilai dari file kode, karena gaya
  Hari dibuat sebagai gambar, bukan CSS).
- Ciri: latar polos terang, bentuk sederhana, warna muted, teks gelap.
  Cocok untuk explainer tenang; tidak cocok untuk adegan gelap/dramatis.
